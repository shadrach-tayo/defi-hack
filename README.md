# LOP Protocol

LOP Protocol is a decentralized trading protocol that enables Time-Weighted Average Price (TWAP) order execution on Ethereum.

## Overview

The protocol consists of:

- Smart contracts for TWAP order execution and management
- Web interface for interacting with the protocol
- Supporting infrastructure and tooling

## Key Features

- Customizable execution windows for TWAP orders
- Configurable fill counts and intervals
- Order tracking and management
- Secure and permissionless execution
